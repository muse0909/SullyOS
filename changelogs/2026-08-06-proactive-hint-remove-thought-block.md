暮色 22:13 反馈"为什么要写我加的"——"我加的"指 Mavis 加的，不是暮色加的。

**规则**：以后写代码注释 / commit message / changelog 时，**不要擅自加"Mavis 修了 XXX" / "暮色 8-6 加回"这种标识**——除非暮色明确要求。暮色工作流偏好之一是"改动要干净，不要堆注释"。
