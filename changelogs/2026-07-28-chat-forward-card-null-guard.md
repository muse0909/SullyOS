# 聊天页转发卡片空消息过滤

**日期**：2026-07-28  
**涉及 commit**：`待提交`

## 改了什么
- 给聊天页的转发卡片 `ForwardCard` 加了消息过滤，只保留有 `role` 的合法消息。
- 转发卡片展开后渲染消息时，不再直接遍历原始 `forwardData.messages`，避免 `null.role` 直接炸页。

## 动了哪些文件
- `components/chat/MessageItem.tsx` —— 转发卡片里先清洗消息，再进入列表渲染。

## 踩坑 / 需要知道的（重要）
- 这次崩溃不是主聊天列表，也不是搜索抽屉，而是转发卡片展开后的独立渲染路径。
- 线上报错里的 `qs.role` 对应的就是这里直接读消息对象字段，坏消息一进来就会把整页带崩。

## 备注
- 已跑 `npm run build` 通过；大 chunk warning 是项目既有提示。
