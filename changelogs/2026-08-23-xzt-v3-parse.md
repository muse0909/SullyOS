# 2026-08-23 小纸条 v3 解析层：3 种 token + 划线 + pickNoteStyle

## 改了什么

### hooks/useChatAI.ts（5.9d 解析块）
- 新增 3 种 token 正则：`XIAO_ZHI_TIAO` / `XIAO_ZHI_TIAO_HIDDEN` / `XIAO_ZHI_TIAO_TIMED`
- 优先级：visible > hidden > timed（AI 同时输多个取第一个）
- 三种共用每天 5 条上限
- TIMED 解析失败 / 时间过期 → 走"立即可见"兜底
- 藏信（HIDDEN/TIMED）**不** addToast；visible 才弹"X 给你塞了张小纸条"
- 1h 重复去重 + 5/天硬限保留
- 用 `pickNoteStyle` 选样式：css → `note.style = className`；image → `note.styleImageUrl = url`

### context/OSContext.tsx（主动消息路径）
- 跟 useChatAI 同步加 3 种 token 解析
- 同样的优先级 + 兜底 + 藏信不通知
- 主动消息 AI 输出 token 时也走 pickNoteStyle

### utils/chatPrompts.ts（小纸条 prompt 段）
- 加 3 种 token 说明（暮色 8-23 v3 命名）
- 加划线说明（40% 概率 + `<s>...</s>` 用法）
- 给示例：`[[XIAO_ZHI_TIAO: 今天看见你笑了，<s>真好看</s>傻乎乎的。]]`
- 仍说"一次最多 1 条 + 一天 5 条（三种合计）"

### utils/xiaoZhiTiaoStyles.ts 之前 commit 已加
- `pickNoteStyle` 函数 + `BUILTIN_NOTE_STYLES`（8 套 CSS）
- 这次 useChatAI / OSContext 都调它

## 行为

| AI 输出 token | 解析后 | 通知 | 存到 note.style? |
|---|---|---|---|
| `[[XIAO_ZHI_TIAO: 立刻]]` | visibility='visible' | ✅ addToast | 是（pickNoteStyle 选）|
| `[[XIAO_ZHI_TIAO_HIDDEN: 藏]]` | visibility='hidden', isTimed=false | ❌ | 是 |
| `[[XIAO_ZHI_TIAO_TIMED: 2026-08-25 22:00 \| 定时]]` | visibility='hidden', isTimed=true, hiddenUntil=ts | ❌ | 是 |
| `[[XIAO_ZHI_TIAO_TIMED: 过期时间 \| ...]]` | visibility='visible' 兜底 | ✅ | 是 |
