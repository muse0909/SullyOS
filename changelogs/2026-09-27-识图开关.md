## 踩坑 / 需要知道的（重要）
- **第一步的多模态直传逻辑完全保留**：cleanedApiMessages 不再砍图片，Gemini 主请求体数组转 parts 都还在
- **老用户行为变化**：配了识图 API 的用户**第一步提交后变成双调用**，第二步提交后变成"开关关闭时不调用"（除非主动开启）。如果之前配过识图 API 又是多模态主模型，第一步到第二步之间会出现"识图 API 调了但主模型也直传"的过渡
- **开关状态读取**：`effectiveApi.enableVisionApi` —— 跟其他 vision 字段一致（全局 + 角色级 apiConfig 覆盖）
- **默认行为**：`undefined` 视作 `false`，不调识图 API，主模型直传看图（Gemini/Claude/GPT-4o 多模态）
- **不动文件**：
  - Chat.tsx 发图流程 —— 不动
  - imageBedUpload.ts —— 不动
  - ApiQuickFloat.tsx —— 这步先不动（暮色要求只改 Settings）
  - Base64 存储 —— 不动
  - 图片记忆功能 —— 不动
