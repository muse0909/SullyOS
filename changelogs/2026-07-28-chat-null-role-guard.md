# 聊天页空消息崩溃修复

**日期**：2026-07-28  
**涉及 commit**：`d3c1196`

## 改了什么
- 聊天页统一过滤掉 `null` / 非法消息，避免渲染时读到 `role` 直接崩溃。
- 把自动语音扫描、重新生成、选中复制、最近消息、主动消息去重这些会摸消息尾巴的地方，统一改成读干净后的消息数组。

## 动了哪些文件
- `apps/Chat.tsx` —— 加消息校验和清洗，顺手把几条脏数据入口补上。

## 踩坑 / 需要知道的（重要）
- 这次不是底层 API 或 IndexedDB 本身坏了，是聊天页里混进了空消息，页面按老习惯直接读最后一条就会炸。
- 只修一个读口不够，得把会碰 `messages` 尾部的几个地方一起换掉，不然过一会儿还会从别的入口炸回来。

## 备注
- `scripts/inspect-idb.html` 没动。
