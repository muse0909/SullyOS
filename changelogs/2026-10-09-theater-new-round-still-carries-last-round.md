**日期**：2026-10-09
**涉及 commit**：`c4be5d74`

## 改了什么

> 不展开剧情感悟不主动聊感情」—— 后面接一段英文的自我纠正
> （*Wait, the system instruction says… User, I shouldn't summarize. But based…*）

他的原话：「不记得之前的剧情，不用总结，不主动聊感情是什么意思？上一轮的存记忆里了啊。
不是非要他忘记之前的，是说剧场聊天页不要再把上一轮的记录都带过来。
一轮结束了就清掉这边的记录，新开的就是下一轮了。但是要让他知道现在是开了新的一轮。
也要让角色知道之前看到哪了，这样角色会更好接。

上次看到了第 x 集，继续一起观看吧。消息上下文会带人设，让角色保持原本人设就可以了。」

## 病根：「不再读上一轮的剧场记录」这件事**只做了一半**

`boot()` 里第 1 步的注释写着「不再读上一轮的剧场记录（10-08 18:30 暮色定的）」，
当时也确实删了一条道。但**第 3 步「灌历史」那条道没堵**：

```ts
history = all
  .filter(去掉工具标签)
  .filter(去掉 ctrl 垃圾)
  .slice(-HISTORY_TURNS)     // ← 来者不拒
```

剧场里说的话（`source === 'theater'`）和每场结束时写的那张折叠卡片，
全被当成普通历史灌进了新一轮的会话。

**所以「每一轮从零开始」从头到尾就没真正生效过。** 模型一边眼前挂着上一轮
从头到尾的对话，一边被提示词要求「你是全新的、不记得之前」——
它当然懵，于是把整段要求背给用户听，还开始自己纠正自己。

截图里那句 `不记得之前的剧情` 不是它编的，**是它把提示词复述了一遍**。

## 三件事各归各位

| | 原来 | 现在 |
|---|---|---|
| 聊天框 | 上一轮的话照带 | 第 3 步排掉 `source==='theater'` 和 `isTheaterMemory` |
| 记忆 | 还在（记忆宫殿照旧注入） | 不变 |
| 知道是新一轮 | 靠提示词说「你是全新的」 | 连接上后**发一条真实消息**点明 |
| 知道看到哪了 | 完全没有 | 开场那句里带「上次看到第 X 集」 |

主聊天的**日常记录保留** —— 同一个角色，日常里聊到哪他也该记得，
人设也是从这儿和角色卡一起带过去的（暮色：「消息上下文会带人设」）。

## 踩坑 / 需要知道的（重要）

### ① 开场那句不显示、不入库（有意为之）

「用户邀请你一起看《X》…继续一起观看吧」**不是暮色打的字**。
显示成用户气泡等于骗他显示；入库又会混进主聊天上下文。
跟之前那个集末问句一个处理：**只发给模型**，界面上不留痕。

要在手机上确认它发了没，读调试口里的 `window.__liveTx.last`，
找 `OPEN-round` 那条。（`kind` 参数就是为这个加的。）

### ② 只在「邀请了一起看」的时候发

没邀请它连画面都没有，说「邀请你一起看」是假的。
那种情况提示词里另有一支（`see === false`）。

### ③ 「上次看到第几集」取的是**最后一张**同剧卡片，不是全场最大集号

他可能看完 10 集又倒回去重看第 3 集 —— 那「上次看到」就该是第 3 集。
`theaterEpisode` 是那一场的最后一集，没有就退回该场集号的最大值。

### ④ 换剧**不会**重新打招呼（已知边界，没自作主张改）

`cfgKey` 只认角色 / 模型 / 地址 / 有没有邀请，**不认剧名**。
所以一轮里换剧不会重连，开场那句也就只在一轮开始时发一次。
而且提示词里那行「剧名：《X》，现在在第 N 集」是建会话时定死的，
换剧之后它还指着上一部 —— **这是同一个病根的另一头**。

要让「换剧 = 重新打招呼 + 提示词换成新剧」，得把剧名并进 `cfgKey` 触发重连，
**代价是换剧那一刻连接会断一次**。暮色没要求，我没动，等他点头。

## 备注

- 暮色问「剧场卡片内容会不会注入主聊天上下文」—— **会**。
  剧场卡片不带 `source`，在 `chatPrompts.ts` 的 `buildMessageHistory` 里被标成 `[聊天]`；
  剧场里说的话标成 `[剧场 《剧名》第N集]`。那道函数只按「隐藏线之前」和
  「记忆宫殿已处理」过滤，**没有剧场过滤**。
  想让主聊天模型认出卡片是剧场记录，得给它单独的标记 —— 等他说要不要。
- 提示词里「不用总结」「不主动聊感情」这两条**没动** —— 那是他之前要的
  （去掉集末问句 / 不要解说员腔）。他这次是把模型复述的那一整句一起拎出来问的，
  没单独指这两条。没把握就不动，已当面问他。
