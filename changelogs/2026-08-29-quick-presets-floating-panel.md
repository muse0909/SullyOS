# 2026-08-29 聊天外观：浮层恢复「快速预设」页签

暮色 8-29 反馈：在 Vercel 部署上看「聊天界面」页找不到"快速预设"和"自定义 CSS"。

## 暮色反馈的"看不见"

8-27 第四步把"快速预设"section 从浮层 page 0 拎到主区域 groupClass section（跟"自定义 CSS"合并），删了浮层 page 0。暮色习惯了在浮层里找"快速预设"页签（之前 8 个预设网格在浮层 page 0），新版本在浮层里找不到这个页签，**以为整个功能没了**。

实际上主区域 section 还在（在「实时预览」section 下面，滚下去能看到完整编辑区），但暮色没注意到。

## 修法

**两个入口同时存在**：
- **浮层**末尾加一页「快速预设」（page 5）—— 暮色在浮层里能切到熟悉的页签
- **主区域 groupClass section** 保留不变（"快速预设 + 自定义 CSS"）—— 滚下去是完整编辑区（textarea + 下拉 + 3 按钮 + 删除）

```
外观 → 聊天界面 tab
├ 实时预览 section（聊天壳预览）
├ 【快速预设 + 自定义 CSS】section  ← 主区域，inline 完整编辑
├ 浮层入口说明 + 圆气泡
└ 浮层（fixed 浮在底部，6 页）
   ├ 快速预设（原 page 0）─── 暮色能在浮层里切预设
   ├ 聊天壳
   ├ 头部
   ├ 气泡与头像
   ├ 细节微调
   └ 表情包与输入栏
```

**两个入口做的事一样**——都是 `updateTheme({ ...FINE_TUNE_DEFAULTS, ...preset.config })`，点哪个预设都会改 OSTheme 字段。

## 关键设计决策

| 项 | 选择 | 理由 |
|---|---|---|
| 「快速预设」在浮层哪个位置 | 末尾（page 5） | 最小改动——保持现有 page 0~4 编号不变，只在末尾追加 |
| 主区域 section 是否还保留「快速预设」上半 | 保留 | 暮色 8-27 明确说"挨着快速预设，都在一个框里"——独立 section 不符合 |
| 两个入口（浮层 + 主区域）是否重复 | 允许 | 两个入口做的事一样，但暮色在不同位置需要入口；不重复 state |
| 浮层 page 5 加提示 | 加 | "想编辑自定义 CSS 请用下方主区域"——避免暮色在浮层里找不到自定义 CSS 又以为没了 |

## 涉及文件

  - 浮层新增 page 5 = 快速预设（提示语 + 8 个预设网格 + 跳转提示）
